# 校园二手交易秒杀平台前端重构规范 (Frontend Refactoring Spec)

## 1. 定位与目标 (Positioning & Goals)
本项目从传统的“二手交易平台”升级为“校园二手交易秒杀平台”。为了匹配“秒杀（Flash Sale）”这一核心特性，前端界面需要呈现出紧迫感、高转化率、以及更现代化的校园社交属性。

**核心目标：**
- **视觉升级**：引入秒杀红/橙为主色调，配合校园青春活力的辅助色。
- **交互强化**：首页增加“限时秒杀”专区和倒计时元素，突出商品稀缺性。
- **响应式适配**：优化 Element UI 的栅格系统，确保在移动端和 PC 端均有良好体验。
- **性能优化**：简化 DOM 结构，减少冗余加载，保障秒杀时页面的渲染效率。
- **平滑兼容**：在不修改后端 API 结构的前提下，通过前端逻辑模拟/接入秒杀状态，保证业务逻辑正常。

## 2. 设计规范 (Design System)

### 2.1 色彩系统 (Color Palette)
- **主色调 (Primary)**: `#ff4d4f` (秒杀红) - 用于核心操作（如“立即秒杀”、“抢购”按钮）。
- **辅助色 (Secondary)**: `#ff7a45` (活力橙) - 用于强调信息（价格、倒计时）。
- **背景色 (Background)**: `#f5f7fa` (浅灰) - 提供清晰的内容层级。
- **文字色 (Typography)**: 
  - 主标题：`#303133`
  - 正文：`#606266`
  - 辅助文字：`#909399`

### 2.2 布局规范 (Layout Guidelines)
- 采用顶部固定导航栏 (Fixed Header) + 内容区 (Main) + 底部版权 (Footer) 结构。
- 采用 Flex 布局实现自适应卡片流。
- 核心内容最大宽度控制在 `1200px`，两侧留白，居中对齐。

### 2.3 核心组件重构要求 (Component Requirements)

#### 导航栏 (AppHeader)
- 品牌名更新为“校园二手秒杀”。
- 增加悬浮阴影，背景纯白。
- 搜索框增加高亮特效，优化输入体验。

#### 首页 (Index)
- **首屏 Banner**: 增加轮播图，展示近期秒杀活动。
- **限时秒杀专区**: 动态生成一个倒计时模块，筛选出价格极低（或随机抽取）的商品作为秒杀商品展示。
- **商品卡片**: 鼠标悬浮(hover)时增加上浮动画和阴影加深效果；将价格与原价对比显示（虚拟原价，放大折扣感）。

#### 商品详情页 (Idle Details)
- 购买按钮变更为“立即秒杀”或“抢购”，使用大尺寸红色按钮。
- 增加库存/限购提示（如“仅剩1件”）。

## 3. 技术实施方案 (Implementation Plan)
1. **全局样式**：在 `App.vue` 或新建 `global.css` 中注入主题变量，覆盖 Element UI 默认的蓝色主题为红色/橙色主题。
2. **组件更新**：逐个更新 `AppHeader.vue`、`index.vue`、`idle-details.vue` 的 DOM 和 CSS。
3. **交互逻辑**：使用 Vue 的计算属性和定时器实现倒计时逻辑，无需后端提供实时倒计时接口即可达到视觉要求。
4. **清理与优化**：移除多余的内联样式，统一采用 class 控制。
